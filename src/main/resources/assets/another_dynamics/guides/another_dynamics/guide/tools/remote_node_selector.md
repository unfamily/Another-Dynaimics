# Remote Node Selector

<ItemImage id="another_dynamics:remote_node_selector" />

Right-click a block to **bind** a remote destination for extractor / retrieve modes. The tooltip shows the bound position. Select another block to rebind.

This is Another Dynamics’ alternative to **Pipez-style remote destination** targeting: point an extract/retrieve face at a block without running ducts all the way to that inventory.
