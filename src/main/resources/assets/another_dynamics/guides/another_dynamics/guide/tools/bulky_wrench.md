# Bulky Wrench

<ItemImage id="another_dynamics:bulky_wrench" />

The **Bulky Wrench** (and any other wrench in the common wrench tags, such as `#c:tools/wrench` / `#c:wrenches`) can **disconnect** faces on **ducts** and **Project Duct**.

Use it to shape connections, rotate, or clear a node face without breaking the whole run where the mod allows it. The same tools work on Project Duct scaffolds before you convert them to real ducts.
