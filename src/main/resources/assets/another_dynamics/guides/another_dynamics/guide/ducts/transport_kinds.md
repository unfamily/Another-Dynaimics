# Transport kinds

Different ducts move different things:

| Kind | Moves |
|------|--------|
| **Item** | Items |
| **Fluid** | Fluids |
| **Universal** | Items and fluids on one network |
| **Flux** | Energy (FE) |
| **Heat** | Heat (when supported) |
| **Gas** | Chemicals / gas (when supported) |

Speed and capacity depend on the duct type and any modules you install. Some kinds only appear if the needed companion mods are installed — see the grid on [Overview](overview.md).
